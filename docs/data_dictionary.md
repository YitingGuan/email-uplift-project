# 数据字典

来源为Hillstrom公开邮件实验，共64,000条记录，12个原始字段。结果窗为邮件实验后两周。

| 字段 | 含义 | 时间属性 | 本项目用途 |
|---|---|---|---|
| recency | 距上次购买的月份数 | 实验前 | 建模、平衡诊断 |
| history_segment | 历史消费分档 | 实验前 | 保留，未重复入模 |
| history | 过去一年消费金额 | 实验前 | log1p后建模、协变量调整 |
| mens | 过去一年是否购买男装 | 实验前 | 建模、交互分析 |
| womens | 过去一年是否购买女装 | 实验前 | 建模、交互分析 |
| zip_code | Urban、Rural、Surburban等粗粒度区域分类 | 实验前 | 类别独热编码，保留原拼写 |
| newbie | 是否过去12个月的新客户 | 实验前 | 建模、交互分析 |
| channel | 过去购买渠道Web、Phone、Multichannel | 实验前 | 建模、描述汇总 |
| segment | Mens E-Mail、Womens E-Mail、No E-Mail | 随机分配 | 处理/对照定义 |
| visit | 后续两周是否访问 | 实验后 | 主结果 |
| conversion | 后续两周是否购买 | 实验后 | 次结果，不能当visit模型特征 |
| spend | 后续两周实际消费金额 | 实验后 | 次结果，不能当模型特征 |

派生record_id为原文件行号，不是原始客户ID。派生treatment为当前二组比较的0/1标记。log_history=log(1+history)。

没有客户性别、年龄、真实地区编码、邮件打开记录、逐次点击、订单ID、逐日时间或投递成本。不能凭这份数据构造真实留存、打开率、逐日归因、多触点路径或实际利润分析。
